# 亲子卡片在线版

`index.html` 是首页。首页展示拼音字母卡、识字 422 字、识字 1000 字、会意字、部首家族、韵语与声音、情绪小怪兽。

**刻意不在首页展示：**`xiangxing.html`（象形字卡）保留直达页面；`拼音拼读卡.html` 只在本地 `孩子/拼音卡集/` 保留，不发布为 `pinyin-pindu.html`。这两项是内容选择，不是漏链。

每套已发布卡片都有“返回首页”。打开或切换卡片时，会立即把当前位置写入同一浏览器、同一站点的 `localStorage`；从首页进入时，先恢复该卡组上次的位置。换浏览器、清理站点数据后，记录不会跨端保留。

本地源码在 `/Users/ping/C 行动_与人交流/孩子/`，`src/` 是仓库内备份。修改后运行 `python3 tests/test_navigation_progress.py`，它用本机 Chrome 检查 8 套已发布页面的入口、返回按钮、进度记录、恢复和窄屏布局。

## 访问统计

已发布的首页和 8 套卡片页（包括保留直达的象形字卡）共用 Google Analytics 4 属性 `561759969` 的网站数据流，衡量 ID 为 `G-V23C1X2DQX`。拼音拼读卡不发布，因此不在统计范围内。

每页通过 `analytics.js` 接入。页面先正常加载；家长首次选择“家长同意统计”后，浏览器才异步加载 Google 标签。选择“暂不统计”不会加载标签，仍可使用全部卡片。首页底部的“隐私与统计设置”可以更改选择；取消同意后，后续页面不再加载标签。统计仅记录页面访问等默认信息，不添加卡片进度、姓名或自定义事件；页面和来源地址中的查询参数会去掉，避免把 `?n=` 进度传给统计服务。增强型衡量和广告相关信号已关闭。

同意前的访问不会进入 GA4；中国大陆网络对 Google 上报地址的连通性也可能导致漏计。因此报表数字是可测到的访问量，不应当作实际总访问量。本站只配置 Google Analytics，没有接入百度统计。

从源码重新生成并覆盖发布 HTML 时，保留每页 `<head>` 中的 `<script defer src="./analytics.js"></script>`。运行 `python3 tests/test_analytics_coverage.py` 检查全部 9 个发布页的接入，另运行上述浏览器回归测试。
