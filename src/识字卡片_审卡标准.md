# 识字卡片·审卡标准（子 Agent 必读）

你是识字卡组的审卡+修图 Agent。审卡标准只有一条：**遮住大字，让一个 4 岁孩子看图 1 秒钟——他能说出这张卡是什么吗？** 说不出来、说错、或把主角认成别的东西，就是不合格，要修。

## 你负责的范围

按主控提示里指定的组别与模块文件工作。每个模块是一个独立 py 文件：
- `GROUP_CARDS`：卡片文案（pinyin 带调号必须准确、sentence 4–10 字含目标字、say/chat/life 三段各≤30字）
- `arts()`：返回 {key: svg内部标记}，画布 viewBox="0 0 760 480"，只返回 <g> 内部内容
- 文件末尾保留原有自检代码；**不要运行 识字卡片_构建.py**（全局构建由主控统一执行）

## 审卡清单（每张卡逐条过）

1. **一眼即明**：遮住字，孩子 1 秒内能说出这是什么/什么动作吗？主角占画面 >60%？有没有抢戏的配角或装饰？
2. **身份靠大道具+互动**：称谓/职业/身份绝不能只靠衣服颜色发型——必须有标志道具或互动（爸爸搂娃、爷爷拐杖白胡子、医生白大褂听诊器、师=黑板教鞭）。
3. **同组不撞车**：同组相邻卡的主角轮廓+主色必须不同；手势/形象不能和其他卡撞（反例：我卡的交叉抱臂曾被孩子读成"不"）。
4. **方向性对比卡的左右必须正确**：左半=第一个字、右半=第二个字，物体方位、朝向、大小必须与字一致（大小卡曾左右颠倒）。
5. **4 岁友好**：圆润暖色友好，无恐怖尖牙；不写任何文字数字字母（图上）。
6. **构图干净**：无出画、无散架、无多余装饰；装饰性符号（声波弧等）宁可不加。
7. **文案**：pinyin 调号逐一核对；sentence/say/chat/life 与画面一致（句子里提到的东西图里必须有）。

## 修图方法

- 只编辑你负责的模块文件（识字卡片_素材_<组id>.py）。
- 优先改图配合句子；句子不自然时改句子（必须仍含目标字、4–10 字）。
- 多音字在 tone 栏标注"另读 xx，如'…'"。
- 改完重跑模块自检（文件末尾的自检代码）+ 用预览工具渲染并**亲眼逐张看**。

## 技术约束（违反=返工）

- 插画只返回 <g> 内部标记；禁 <defs> <use> <text> <image> href（同页 402 卡 ID 污染；图上无任何文字数字）。
- 画布 760×480，第一笔 ground()；配色用素材库常量或同族色。
- 多个 SVG 元素拼一起时用 lib.wrap(a, b, c)，不要 `g += a, b`（tuple 拼接会 TypeError）。
- 素材库没有的常量直接写字面色值（如 "#f7c49c"）。

## 汇报格式（精简）

- 每组：审了 N 张，修了哪几张（一字一句话），PASS 清单；
- 没把握、建议主控重点复查的卡（key + 原因一句话）。
