# 识字卡片插画设计规范（子 Agent 必读）

你负责为一个 4 岁孩子的识字卡组设计一批字的插画与文案。成品会合入单文件 HTML，家长在飞书里打开陪孩子翻看。

## 必读文件（动手前按顺序读完）

1. `识字卡片_字库.py` —— 300 字分组与顺序（GROUPS）
2. `识字卡片_素材库.py` —— 画风原语与组件 API（E/C/R/L/P/PG、ground/ball/table/box/cup/jug/stream/bowl/spoon/hand/kid/star5/heart/drop/cloud_p/flower5/tree_round/check，以及 PALETTE 色板常量）
3. 本文件

## 你要交付什么

一个组模块文件 `识字卡片_素材_<组id>.py`，包含：

```python
# 组卡片文案数据（不含种子字：日、山、水、手、吃、大小、上下 由构建脚本提供）
GROUP_CARDS = [
    {"char": "猫", "pinyin": "māo", "tone": "第一声",
     "sentence": "小猫喵喵叫。", "say": "…", "chat": "…", "life": "…"},
    {"pair": ["左", "右"], "key": "左右", "pinyin": "zuǒ · yòu", "tone": "第三声 · 第二声",
     "sentence": "左手右手。", "say": "…", "chat": "…", "life": "…"},
]

def arts():
    return {"猫": "<g>…svg 内部标记…</g>", "左右": "…"}
```

- `GROUP_CARDS` 覆盖你分组的**全部**字（种子字除外），顺序与字库一致（可 `import 识字卡片_字库` 自查）。
- `arts()` 的 key：单字卡=字；对比卡=两字连写（如 "左右"）。**种子字不出现在你的文件里**。
- 文件末尾带自检代码，`python3 识字卡片_素材_<组id>.py` 输出卡数与校验结果。

## 卡片文案要求

- **pinyin**：标准汉语拼音带调号（ā á ǎ à），对比卡两字用 " · " 连接；**必须准确**，这是给家长看的。
- **tone**：如 "第一声"、"第三声 · 轻声"。
- **sentence**：4–10 字的生活短句，尽量自然包含目标字（对比卡两句式如 "小球小，大球大。"）；不追求孩子会读，是家长读的。
- **say/chat/life**：家长提示三段。怎么说=指图讲这句字义；怎么聊=一个具体问题；生活里=一个马上能做的动作。每段口语化、≤30 字，不堆术语。

## 插画硬性规则

1. 画布 760×480，函数返回**内部标记字符串**：不带 `<svg>`、不带 xmlns；**禁止** `<defs>` `<use>` `<text>` `<image>`（同页 282 张卡，ID 会互相污染；图上不许出现任何文字、数字、字母、拼音）。
2. 第一笔 `ground()`；主体居中（cx≈380，对比卡两半 cx≈240/560），重心在 y 250–440，四周留白。
3. 一张卡只讲一件事：目标物最大最醒目，配角最多一个；不画星星彩虹等装饰（语义需要除外，如"星"字卡本身）。
4. 配色只用 PALETTE 常量或同族色；体积感用"深一号底色偏移"画法（见 ball 实现）。
5. 有人物动作用 `kid()`，有手部动作用 `hand()`，量数用 `ball()` 等同一物件重复（数字卡的 N 就画 N 个同一物件，两行排列，最多 10；百=10×10 点阵）。
6. **对比卡**：同一物件左右两半只变对比维度（大小=同色球两颗；上下=同一张桌子，球在桌上/桌下）。两半正中留 60px 以上间隔，字在面板上分别压在左右半的正上方（x=240/560），物体必须与各自半边对齐。
7. 动物/人物要友好圆润：圆眼、圆腮红、无尖牙利爪、无血迹阴影；不画恐怖、宗教、钱币、武器（刀=水果刀切苹果场景）。
8. 每张卡的轮廓剪影 + 主色要能和同组其他卡区分（猫和狗不能只差耳朵，主色也要换）。
9. 抽象字（常用字组）按字库里的 note 设计小场景；问号勾叉是允许的符号。

## 自检（交稿前必须全过）

```bash
cd "/Users/ping/C 行动_与人交流/孩子"
python3 识字卡片_素材_<组id>.py        # 输出卡数、 arts 数、与字库比对结果
python3 - <<'EOF'
import xml.etree.ElementTree as ET, importlib.util
spec = importlib.util.spec_from_file_location("m", "识字卡片_素材_<组id>.py")
m = importlib.util.module_from_spec(spec); spec.loader.exec_module(m)
for k, v in m.arts().items():
    ET.fromstring(f'<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 760 480"><g>{v}</g></svg>')
    assert "<text" not in v and "<use" not in v and "<defs" not in v and "<image" not in v, k
    assert "href" not in v, k
print("SVG 全部合法 ✓")
EOF
```
