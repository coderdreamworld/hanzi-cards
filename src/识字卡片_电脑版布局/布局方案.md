## 0. 一句话方案

电脑宽屏（≥1024px）时切换为**三栏字卡台**：左栏插画卡、中栏大字自动笔顺（描红式）、右栏讲解面板，一屏看全所有内容；底部组内胶片条 + 左右箭头/键盘切换卡片。手机竖屏保持现状完全不变。

## 1. 现状问题

| 手机端现状（竖屏） | 电脑端打开时的问题 |
| --- | --- |
| 一屏一卡，插画与大字同卡 | 卡片居中约 720px，两侧大片空白 |
| 「显示笔画」开关：笔画与插画**二选一** | 看笔顺要点击切换，插画就消失 |
| 「提示」开关：讲解默认收起 | 看讲解要再点一次，看不全 |
| 左右滑翻卡 | 无键盘支持，只能点击 |

## 2. 需求理解（请确认）

「所有内容全部展开」= **每一张卡内部的全部模块同时可见**（笔顺动画 + 插画 + 例句 + 讲解），左右切换的是**卡片**（不是 402 张全铺一屏）。若你想要的其实是"全部卡片平铺成墙"，请纠正我。

## 4. 分区明细（数据全部来自现有成品，无新增内容）

| 分区 | 内容 | 数据来源（已内嵌） |
| --- | --- | --- |
| 左栏 插画卡（**放大·等高**） | 列宽 35vw，等高卡片框内插画居中、例句条贴卡底 | `ART[key]`、`card.sentence` |
| 中栏 米字格字牌 | **虚线米字格**（无拼音行）（米白底、棕黄虚线：横/竖/两对角）：粗圆笔迹逐笔自动书写，写完停 ~2s 擦掉重写（可点字牌/↻重写、顶栏可关循环）。格内无底字，参照字看右栏字头 | `STROKES_DATA` + 原页逐笔动画代码（原样复用）；米字格为纯 SVG 线条，无新数据 |
| 右栏 讲解面板 | 字头（字/组/序号）+ 引导语 + 读音/怎么说/怎么聊/生活里 四行 | `tipsHTML` 同源数据，桌面**默认展开** |
| 底栏 胶片条 | 当前组全部字的迷你按钮（当前高亮），点击直达；两侧大箭头；计数 | 当前组 CARDS |
| 顶栏 | 21 组 chips（原分组列表改为平铺）+ 书写循环开关 | `GROUPS` |

**桌面新增能力**：手机端「笔画/插画二选一」在桌面变为**同屏并存**——底字轮廓常驻 + 笔迹书写其上，插画也不消失。

## 5. 交互规格

- **切换卡片**：底栏 ← / → 按钮、键盘 ← / →、胶片条点击；切换后笔顺自动重写。
- **组切换**：顶栏 chips 点击；切组后胶片条更新为该组，定位到第一张。
- **笔顺**：进入卡片 350ms 后逐笔写（每笔 ~620ms），写完停 1.9s 循环；点字牌或 ↻ 重写；顶栏开关可改为「只写一遍」。
- **保留的全局开关**：藏起插画（左栏收起）、讲解显隐（右栏收起）——默认全开。
- **对比卡（20 对反义词，如「上/下」「大/小」）**：中栏两字并排（各约半宽），笔顺先后书写（沿用原 multi 逻辑）。
- **无笔顺数据的字**：当前 422/422 全覆盖；兜底逻辑保留（只显底字）。

## 6. 响应式策略

- `< 1024px`（含微信手机端）：**现有竖屏布局原样保留，零改动**。
- `≥ 1024px`：三栏字卡台。1024–1280 三栏紧凑排列；≥1440 左右栏固定宽、中栏弹性；≥1920 整体最大宽度约 1680px 居中，避免过宽阅读疲劳。
- 平板横屏（如 iPad 1024×768）落入桌面布局，也能用。
