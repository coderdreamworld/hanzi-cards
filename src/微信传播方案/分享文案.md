## 今后更新线上版本的流程

1. 正常改卡、`python3 识字卡片_构建.py` 出新 `识字卡片_422字.html`；
2. 复制到 `微信传播方案/发布/github-pages/` 覆盖 `shizi-422.html`（注意保住文件头 favicon 那一行，或在覆盖后重跑当时的注入脚本）；
3. `cd 发布/github-pages && git add -A && git commit -m "更新卡片" && git push`；
4. 等 1~2 分钟 Pages 重建完成，链接内容即更新（链接不变，群里旧消息里的链接也会是新内容）。

若按报告 4.4 节接入 EdgeOne Pages 后，第 2~4 步可省——push 仓库即自动部署。
