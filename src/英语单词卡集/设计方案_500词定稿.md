# 英语单词卡 · 500 词词库定稿方案

日期：2026-11-04 ｜ 状态：**用户已确认；25 组 500 词条已完成**
配套：`english-words.html`；每词一张插画、单词音频、逐字母读名与听音选图。500 是内容库规模，按兴趣选用，不是4岁孩子的达标量。

## 一、这批词怎么选的

| 依据 | 说明 |
| --- | --- |
| 已有英语 demo | 沿用其中动物、食物、课堂动作、家庭等主题；并非原46词逐项全收 |
| 主题组织参考 | 参照小学英语与少儿英语常见生活主题；这份500词为项目自编词库，未逐词核对为某版PEP或剑桥官方清单 |
| 生活与可画性 | 兼顾常见物体、可演示动作、情绪、颜色、数量与方位；纯语法词（the/is/and 等）未收 |
| 数量口径 | 共500个不同词条，含 `ice cream`、`thank you` 等常用短语；不把空格拆词，也不按词形变体重复凑数 |

## 二、怎么分类（25 组）

- 主题优先：吃的（水果/蔬菜/食物）、动物（陆地/水空）、身体、家庭、家（家居/餐厨）、
  学校、玩具、交通、自然、场所、时间季节……
- 词性成组：动作拆「身体动作/生活动作」两组，形容词拆「对比上/下」两组（相邻卡不撞参照物），
  另有情绪、礼貌应答、方位三组。
- 每组 10~22 词：主题内便于选卡，每次可只挑几张，不设一天一组的要求。
- 500 词整：已脚本校验无重复、总数恰 500。

## 三、每词画什么（划分原则）

1. **主体放大**：插画是理解单词的唯一线索，主体占画布 55%~75%；
2. **特征夸张**：该物的辨识特征必须一眼可辨（长颈鹿=长脖吃高叶、勺子=椭圆头长柄）；
3. **系列化**：同组用统一"戏台"，词图对应零歧义——
   颜色组=大蝴蝶换色＋同色小物；数字组=数苹果（图上无数字）；方位组=猫与纸箱关系；
   形容词组=主角物＋对比参照物；动作组=素材库 kid() 标准姿势；
4. **画上无文字**：延续中文卡规矩，图上禁一切文字数字，字母识别只靠卡面大字母区；
5. 同组相邻卡主色与轮廓错开，避免"连页同色"。
