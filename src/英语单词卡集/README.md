# 英语单词卡

本地权威工程：25组500词条，每词一张手绘SVG插画。包含常用单词与短语（如 ice cream、thank you），按词条计数。为亲子选用的内容库，不设孩子短期掌握全部内容的要求。

- 成品：`english-words.html` + `audio/`（相邻摆放即可离线打开）。
- 在线直达：<https://coderdreamworld.github.io/hanzi-cards/english-words.html>。
- 首页：<https://coderdreamworld.github.io/hanzi-cards/>，入口在识字卡之后。
- 词表、中文释义、分组与画面构思：`词库500.py`；文字表格见 `设计方案_500词定稿.md`。
- 绘图源码：`素材/素材_en_*.py`；人体原型只读调用上一级的 `识字卡片_素材库.py`，动作场景局部工具在 `素材/动作组件_en.py`。

## 使用

手机：左右滑动或点底部箭头换卡；点中间分组按钮选择25个主题。点图或「单词」听当前词；点「拼读」逐字母读名，随实际音频进度高亮，最后读整词。「听音选图」提供四个图片选项，答对后庆祝，再进入下一题。

桌面：960px起自动三栏，插画、单词字母、主题提示同屏；顶部切主题，底部点词或箭头换卡。

「拼读」是字母名拼写（C, A, T，然后 cat），不等同于自然拼读音素。单词与字母均使用预生成 Samantha 美音m4a，浏览器首次自动播放可能需要点一下「单词」。

进度保存在当前浏览器的本站点存储：首次直连显示第一张且不覆盖旧进度；主动换卡并停留满1.5秒才写入。通过首页进入（`?from=hub`）恢复上次保存位置。不同浏览器与设备不自动同步。

## 构建与验证

```sh
python3 构建.py
python3 检查英语卡.py
```

检查：500词条、25组、锁版词表顺序、500张非空且不完全重复图稿、XML、1000条词音/拼读音频、26个字母音频、0~12数字卡实物数量、成品JavaScript语法。

`python3 构建.py --partial` 生成本任务内 `预览_en.html`。`python3 渲染验收图.py` 生成 `验收/` 内逐组PNG（每页最多9张），可加 `--groups <组id> ...` 只渲染改动组。图像检查须结合词义和实际画面，不能只靠脚本断言。

重新生成音频：`python3 生成音频.py --group all`（默认跳过已有文件）；字母：`python3 生成字母音频.py`。生成环境需要macOS say、Samantha、ffmpeg。最终页面使用音频文件，不依赖设备系统TTS。

## 维护与发布

本地工程为权威副本。发布仓库位于 `../微信传播方案/发布/github-pages/`：

- `english-words.html`复制到仓库根；`audio/en_*.m4a`并入根 `audio/`，保留其他卡组音频。
- 源码文档备份到仓库`src/英语单词卡集/`；音频只在根`audio/`发布，避免重复备份。
- `index.html`首页已增加「英语单词卡」入口。
- 发布前跑完整性与视觉回归；推送后回读线上HTML与抽样音频sha256。音频修改须更新构建器VER，避免同名缓存。

`英语单词卡_试点20词.html`及`设计草案.md`为早期存档，正式结果以`english-words.html`为准。当前词库为项目自编，主题参考儿童生活情境，未标成任何教材或考试的官方完整词表。
