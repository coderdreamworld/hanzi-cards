# 英语单词卡 · 画卡规范（子代理必读，硬规则）

本规范约束 `素材/素材_en_*.py` 的生产。参照画风基准：`../识字卡片_1000字/素材/素材1000_dongwu.py`（已验收动物卡）。

## 画布与形式

- 每张插画 = viewBox `0 0 760 480` 画布的**内部内容字符串**：只返回 `<g>` 内部形状标记，不带 `<svg>` 包装、不带 xmlns。
- **禁止** `<defs>`、`<use>`、`<text>`、`<image>`、渐变、滤镜；**图上禁止出现任何文字与数字**（含字母——英语单词卡靠画面表达，词本身在卡面文字区）。
- **所有元素必须在760×480画布内**。半身特写只画到肩，不把完整人形下半截放到画布外。构建器检查XML、标签与键；最终边界在浏览器用`getBBox()`按实际transform结果验证，不能把局部坐标直接当画布坐标。页面额外限制插画视口避免溢出，但裁切不能代替修图。
- 描边仅限 `L()` 线段类（肢体、触须、声波线等），形状块**无轮廓描边**、无渐变，扁平绘本风：深一号底色偏移制造体积。

## 组件与配色

- 组件库：`/Users/ping/C 行动_与人交流/孩子/识字卡片_素材库.py`（import 后可用 `E/C/R/L/P/PG/wrap/ground/ball/box/cup/kid/hand/star5/heart/drop/cloud_p/flower5/tree_round/check` 等）。
- 人物/小孩一律 `kid()` 原生组件，**禁手搓人形**；kid 姿势参数见库内 docstring（pose/face/arms/point_at/item/extra）。
- 配色只用素材库 PALETTE（INK/PAGE/GROUND/RED/YEL/TEAL/BLUE/WBLUE/SKIN/HAIR/WOOD/GREEN/SUN/PINK/WHITE 及 *_D/_L 变体）或其同族色（新增色须是同族明暗变体）。
- 每卡**第一笔 `ground()`**（默认参数即可），主体居中偏下，底边落在地面椭圆上（y≈430 一带）。

## 主体要求（词图对应的生死线）

1. **主体放大**：英语卡插画是理解单词的唯一线索，主体应占画布高度 55%~75%，一眼可辨。
2. **特征夸张到位**：该物种/物品的辨识特征必须清楚（长颈鹿=超长脖+角、斑马=均匀条纹、勺子=椭圆勺头+长柄……）。
3. **轮廓+主色错开**：同组相邻卡轮廓类型与主色都要错开（相邻不用同主色）。
4. 场景可加 1~2 个辅助小物（ food 用对应容器、动物可用栖息环境），但不得喧宾夺主。
5. 系列组按词库 `note` 字段执行（颜色=蝴蝶系列、数字=苹果一排、方位=猫与纸箱……）。

## 模块格式

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""英语单词卡 <组名> 第 N 段插画（<卡数> 卡）。
一句话说明每卡造型要点。"""
import sys
sys.path.insert(0, "/Users/ping/C 行动_与人交流/孩子")
from 识字卡片_素材库 import *  # noqa: F401,F403

GROUP_CARDS = [
    {"w": "cat", "cn": "猫"},
    # ...顺序与词库一致，字段只有 w / cn
]

def arts():
    return {
        "cat": wrap(ground(), ...),   # 内部内容字符串
        # key 与 GROUP_CARDS 的 w 完全一致
    }
```

- 文件命名：`素材_en_<gid>.py`；一组建不完可拆 `素材_en_<gid>_1.py`、`_2.py`（构建器按去掉 `_<n>` 后缀归组）。**组 id 连字符保留**（如 `dongwu-a`），文件名里同样写连字符。
- `GROUP_CARDS` 与 `arts()` 的键集合必须与该组词库切片**完全相等**（不多不少不重排）。

## 自检通过 ≠ 验收通过

结构断言只保证能解析。**画面质量由集成方目检**（grid 截图逐张看）：比例失调、特征错位、颜色相撞、手臂数不对都要返工。所以画的时候宁可简洁清晰，不要堆砌细节。
