# 英语单词卡集 · 设计草案（试点前定稿）

日期：2026-11-03
定位：4 岁孩子英语启蒙·单词识别卡。与中文识字卡（1000 字/31 组）同构、同一套页面规范，内容换成英语。
产品名（暂）：**英语单词卡 · English Words**

## 一、卡片内容（单卡四要素）

```
┌────────────────────────────┐
│ [插画：与词义一一对应]        │  ← 主视觉（emoji 图形放大 + 地面阴影，贴扁平风）
│                            │
│  A  P  P  L  E             │  ← 字母逐个大字（字母识别）
│  apple                     │  ← 整词（小写，自然拼读形）
│  苹果                       │  ← 中文释义小字（家长用）
│  🔊 重播   🔤 拼读          │  ← 单词音频 / 字母逐个+单词
└────────────────────────────┘
```

- **字母识别**内建：每卡字母逐个大写展示（A P P L E），拼读按钮读 "A, P, P, L, E. Apple."。
- 词性：名词为主，动词/形容词配动作或表情图形。

## 二、页面结构（复用全站规范）

| 规范项 | 取值 |
| --- | --- |
| 宽屏三栏断点 | ≥960px（matchMedia 挂 body.desk-on，与全站六套卡一致） |
| 移动端 | 卡片占满 + 底部上一张/选卡/下一张；左右滑翻卡 |
| 页首 | 🏠 首页按钮（全站统一） |
| 续看 | `hz.last` 写入（停留 1.5s 防抖），首页「继续上次」入口 |
| 游戏 | 听音找字（播单词→四选一图），答对撒花+琶音（复用庆祝） |
| 分组 | 顶部横向 chip 条（主题组），组名双语 |
| 音频 | `audio/` 离线 m4a，URL 带 `?v=` 版本参数防缓存 |
| 字体 | 大字用系统字体粗体（英文无需矢量轮廓） |
