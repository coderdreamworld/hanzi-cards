# src/ —— 既有中文卡片源码备份

本目录保存既有中文卡片的源码，与 GitHub Pages 根目录的发布成品对应。英语单词卡 demo 是单文件原型，其源码即 `../english-word-cards/index.html`，不在此重复存放。
**本目录不参与线上页面**；改页面请改这里的源文件后构建，再同步成品到仓库根目录。

## 对应关系

| 源 | 构建命令 | 发布成品（仓库根） |
| --- | --- | --- |
| `识字卡片_*.py` + `识字卡片_模板.html` | `python3 识字卡片_构建.py` | `shizi-422.html` |
| `识字卡片_1000字/` | `python3 构建.py`（内含部署准备） | `shizi-1000.html` |
| `拼音卡集/拼音卡_*.py` | `python3 拼音卡_构建.py`（⚠️ 会覆盖手工维护的成品，见拼音卡集说明.md） | `pinyin-zimu.html` + `audio/` |
| `汉语启蒙卡集/` | `python3 汉语启蒙_构建.py` | `xiangxing/huiyi/bushou/yunyu.html` |
| `emotion-cards.html` | 无需构建（单文件） | `emotion.html` |
| `logic-board-game/index.html` + `logic-board-game/设计方案.md` | 无需构建；复制 HTML 到发布目录 | `logic-board-game/index.html` |

首页刻意不展示 `xiangxing.html`；它仍保留可直达的发布页。`拼音拼读卡.html` 仅保留在源码中，不发布 `pinyin-pindu.html`。详见仓库根目录 `README.md`。

逻辑桌游独立发布，不加入卡片首页；本机原稿与同步步骤见 `logic-board-game/README.md`。

注：`tools/node_modules` 未入库（npm 依赖，`cd 识字卡片_1000字/tools && npm i` 可重装）。
各目录内的 .md 为调研、方案与核对报告，是修改依据，勿删。
