# 拼音卡集说明

## 当前线上产品

线上只保留 `pinyin-zimu.html` 一套拼音字母卡。页面先由家长或孩子点一次“开始学习”开启浏览器声音权限；此后无论点击上一张、下一张、分类、选卡、桌面卡条，还是在手机上左右滑动，翻到新卡都会立即自动发声，卡面右上角可随时重播或静音。

当前有 7 个子集、138 个展示卡位：

| 子集 | 数量 | 用途 |
| --- | ---: | --- |
| 声母 | 21 | 按《汉语拼音方案》声母表顺序认形、正音 |
| y / w | 2 | 按 2024 修订版统编教材单列，讲清零声母音节的书写规则 |
| 韵母 | 24 | 6 个单韵母、8 个复韵母、1 个特殊韵母、9 个鼻韵母 |
| 整体认读 | 16 | 每个音节一张独立卡 |
| 完整拼音表 | 63 | 复用以上 21 + 2 + 24 + 16 张卡；不是一张总览图 |
| 声调五类 | 5 | 一声、二声、三声、四声、轻声各一张，均有 3 个例词 |
| 易混对照 | 7 | b/d/p/q、f/t、m/n、z/zh、c/ch、s/sh、u/ü |

“完整拼音表 63”的顺序为：

1. 声母 21：`b p m f d t n l g k h j q x zh ch sh r z c s`
2. 书写字母 2：`y w`
3. 韵母 24：`a o e i u ü ai ei ui ao ou iu ie üe er an en in un ün ang eng ing ong`
4. 整体认读音节 16：`zhi chi shi ri zi ci si yi wu yu ye yue yuan yin yun ying`

`u` 没有消失：它不是声母，位于“韵母 24”的第 5 张，也位于“完整拼音表 63”的第 28 张。

## 标准依据

- 教育部《汉语拼音方案》规定声母表为 21 个声母，不含 `y / w`。
- 2024 秋季启用的修订版统编一年级上册把原来的 `i u ü y w` 拆成 `i u ü` 与 `y w` 两课，并明确按 21 个声母教学。
- 《义务教育语文课程标准（2022年版）》要求第一学段能读准声母、韵母、声调和整体认读音节。

## 配音实现

页面不使用不稳定的浏览器 TTS。`audio/` 中的 75 个教学音频均离线预生成：

- 63 个音形项目：用普通话宽式 IPA 锁定一声课堂呼读音；声母不是英文字母名，也不再用“飞、东、天”等任意同声母词代替。
- 5 个声调音频：完整读出声调走向与例词。
- 7 个易混对照音频：先依次播放准确呼读音，再播放辨形或发音提示。

重新生成音频：

```bash
python3 生成标准呼读音.py
```

该命令使用 macOS `Tingting` 普通话语音：IPA 音段由 `生成标准呼读音.swift` 合成，完整说明句由系统语音生成，再统一转成 AAC/M4A。脚本会检查空文件、无音轨、过短音频和超时；全部通过后才替换正式音频，避免半成品进入页面。

## 页面构建与验收

重新构建：

```bash
python3 拼音卡_构建.py
```

验收重点：

1. 构建输出应显示拼音字母卡共 138 个展示卡位。
2. “完整拼音表”选卡面板应为 63 张；开头是 `b`，结尾是 `ying`，并包含 `u`、`ü`。
3. “声调五类”必须恰好有 5 张，每张有调号、声调走势和 3 个例词。
4. 点“开始学习”后，桌面和手机每次翻卡都应请求当前卡对应的 `audio/*.m4a`，且音频无错误。
5. 390×844、375×667、320×568 和 1440×900 下不得出现页面横向溢出；手机底部只保留上一张、选卡、下一张。
6. 已知问题图 `p / f / d / t` 不得再出现多余手、人物、杆件或桌凳式误读。

`拼音拼读卡.html` 仍可由构建器生成，但不在导航和线上入口展示。

## 2026-10-31 晚 · 发音逐项核对（重要）

逐音核对结论见 **`拼音字母卡_发音核对报告_20261031.md`**。要点：

- **当前线上 `audio/` 的 64 个音形项目里有 24 个有确定缺陷**。根因不是选字，而是 `AVSpeechSynthesisIPANotationAttribute` 对中文语音（Tingting）**部分且有损**：它会**静默丢弃**不认识的音素而不报错。
  - `ɪ ʊ` 被丢 → `ai` 读成 `a`、`ou` 读成 `o`
  - `ɻ` 被丢 → `er` 读成 `e`（无卷舌）
  - `ɑ ɥ` 被丢 → `ao`、`üe` 被截断成 0.19 s
  - 塞擦音后的送气符 `ʰ` 被丢 → **`j`=`q`、`zh`=`ch`、`z`=`c` 是字节完全相同的文件**
  - `ɨ` 被清化 → `z c s zh ch sh` 读成「嘶——」而不是「资——」
- 已验证的修法：**能用汉字就不用 IPA** —— 让 Tingting 直接读标准第一声汉字（58/64 有对应字），只有 `fō dē tē nē lē rī` 等 6 个走简单 IPA。
